# Rithick Paul — Portfolio

Responsive personal portfolio made with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and current year

## Run locally
Open `index.html` in a browser or use VS Code Live Server.

## Publish with GitHub Pages
1. Upload these files to the root of your public `my-portfolio` repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Your site should appear at `https://rithickpaul.github.io/my-portfolio/`.

## Personalize before publishing
- Replace `your-email@example.com` with your email address.
- Replace the LinkedIn placeholder link with your profile URL.
- Review project descriptions to make sure they accurately describe your work.
